##Python-based radar alert simulator.

> Radar Alerts are sent as UDP packets to a designator listener as well 
> Expected input is a KML file consisting of coordinates of the Radar (Lat,Long)
> Program will efficiently generate alerts, simulating various scenarios, giving a real feel of alerts detected by the radar geographically 
> An output KML file and CSV file will be generated as a result 
> Program also sends these packets in real-time
